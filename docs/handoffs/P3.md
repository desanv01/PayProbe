## Interfaces and connections
- src/ai/planner.ts: generatePlan(DeepSeekClient, contract), reviewPlan(saved), loadSavedPlan(saved, requireReviewed), toRunnerPlan(plan), Plan, SavedPlan.
- Contract: requirements string <=4000 characters; purchase {amountCents:1..10000,currency:'USD',productId:'sample-guide'} (currency/product default); adapter {version:'1.0',capabilities:P1 capability array}; fulfillmentTimeoutMs 0..10000 default1000; fixtureMode corrected|premature_fulfillment|duplicate_processing default corrected. Purchase IDs are run-derived by P2, never supplied/ignored by planner.
- Plan contains version/provider/provenance ('1.0'/simulated/simulated), contract, selection.scenarios[{id:S1-S4,rationale}]. Duplicate/unsupported scenarios and missing capability requirements reject; S3 requires selected S2. Model never generates code/endpoints or verdicts. Sanitized requirements/rationale only persisted; no raw private prompts/reasoning.
- SavedPlan contains plan/hash/review/AI usage metadata. Generation always yields review:null. Explicit review stores accepted=true, matching SHA256 and UTC timestamp. Execution reparses and validates hash/review; no planner request during run/resume. Hash is a local review consistency check, not a security attestation.
- src/ai/review-store.ts ReviewedPlanStore(store).save(saved): persist reviewed source BEFORE run; attach(runId,saved): compare executed P2 plan and bind source hash AFTER run; forRun(runId): retrieve source. Run/source mapping is not atomic with runner creation: abrupt process death before attach may leave an unbound run, while reviewed source and executed runner plan remain independently persisted. Do not claim stronger crash-atomic linkage.
- src/reporting/report.ts projectReport(RunReport), formatReport(report,'text'|'json'). Uses P2's deterministic findings and evidence IDs unchanged. Missing cases show PENDING, unknown stays unknown. Explicit allowlist redacts secrets/download capabilities; safe simulator approval URL remains actionable, query/fragment removed. Reports label provenance simulated, realPayPalVerified:false and real-validation limits.
- src/ai/explainer.ts explainReport(client,RunReport): receives sanitized bounded observations (<=80 events, <=20KB aggregate observation JSON, per-event <=2500 bytes); every cited ID must belong to the named recorded case and supplied scenario. Missing evidence blocks explanations; omitted evidence is disclosed. Model explanation/hypotheses stay separate from immutable deterministicCases; no verdict mutation. Valid citation IDs cannot prove natural-language claims true; explanation remains AI-generated.
- src/cli/commands/index.ts registerWorkflowCommands(program,deps): deps {client:()=>DeepSeekClient, run:(RunnerPlan,{autoApproveSimulated,reviewedPlan:SavedPlan})=>Promise<RunReport>, resume:(runId,{autoApproveSimulated})=>Promise<RunReport>, report:(runId)=>RunReport|Promise<RunReport>, output?}. P1 owns wrapper wiring with Store/HttpAdapter and ReviewedPlanStore. New output files use exclusive creation, no overwrite.

## Plain headless usage
With main/P1 registration wired:
```
payprobe plan contract.json --out draft-plan.json
# Inspect draft-plan.json before accepting its exact contents:
payprobe plan --review draft-plan.json --out reviewed-plan.json
payprobe run reviewed-plan.json --auto-approve-simulated
payprobe resume RUN_ID --auto-approve-simulated
payprobe report RUN_ID --format text
payprobe report RUN_ID --format json
payprobe explain RUN_ID --out explanation.json
```
Autoapproval explicitly changes simulated orders only. Without it runner pauses and report provides a simulator POST approval URL; resume then continues. No PayPal account is needed.

Example contract (main may publish as examples/download-contract.json):
```json
{"requirements":"Check approval without capture, one delivery after capture, repeated completion processing, and recovery of a lost successful capture response.","purchase":{"amountCents":500,"currency":"USD","productId":"sample-guide"},"adapter":{"version":"1.0","capabilities":["create_order","handle_buyer_return","capture","observe_application","check_download","process_again","reconcile","arm_fault"]},"fulfillmentTimeoutMs":1000,"fixtureMode":"corrected"}
```
